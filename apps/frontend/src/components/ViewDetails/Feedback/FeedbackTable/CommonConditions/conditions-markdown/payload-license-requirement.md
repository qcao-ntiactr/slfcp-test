- ==[Commercial Provider Name]== should be aware that a satellite integrated into a launch vehicle or deployment device without a current FCC authorization may need to be removed from that vehicle or deployment device if the satellite operator's application for an FCC authorization is not acted upon favorably, or for various reasons cannot be granted within a time frame consistent with the launch schedule.
